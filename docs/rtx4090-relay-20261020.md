## 登录与目标

```sh
ssh -J ubuntu@49.232.60.144 -p 2225 centos@127.0.0.1
```

连接路径：客户端 → 腾讯云 `ubuntu@49.232.60.144:22` → 云端 `127.0.0.1:2225` → Windows 发起的反向 SSH 隧道 → `centos@192.168.1.19:22`。

目标是 CentOS 7，主机名 `localhost.localdomain`。`nvidia-smi` 实测索引 0–7 共 8 张 NVIDIA GeForce RTX 4090，每张 24564 MiB。原 `192.168.1.111` 为 8 张 RTX 5090，仍使用 2223 / `user001`；Windows 自身仍使用 2224 / `tsari`。

目标 Ed25519 主机指纹：

```text
SHA256:cavK9dsPoWugv2XDva9fsVoijfY7JghCTQbPHuNLLNg
```

首次连接的新电脑应核对此指纹。可选客户端别名为 `rtx4090-via-cloud`，见仓库 `ops/windows-ssh-relays/config/client-ssh.example.conf`。模板使用独立 HostKeyAlias；首次使用别名需要核验同一主机指纹。

## 定向暂停与恢复

在 Windows 管理员 PowerShell 中执行；只影响新增 4090：

```powershell
$control = 'C:\ProgramData\GAASD-SSH-Relays\bin\Control-Relay.ps1'
& $control -Action Status
& $control -Action Stop -Name rtx4090
# 需要恢复时：
& $control -Action Start -Name rtx4090
```

Stop 会禁用任务并写入停用标记，避免定时触发器重新启动。无需恢复整个旧运行定义或停止 2223 / 2224。源码后续更新使用同一功能分支 `feature/why-cbdes-review`；GitHub 推送不会自动重启任务或发布网站。
