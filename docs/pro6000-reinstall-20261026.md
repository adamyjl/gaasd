## 自启动与版本保护

以下服务/定时器均 enabled 且 active：`ssh`、`zerotier-one`、`gaasd-pro6000-tunnel`、`pro6000-zerotier-mtu.timer`。隧道保留双方 20 秒 / 3 次心跳与 10 秒重连；仅杀掉专用隧道主进程后，systemd 自动恢复，`NRestarts=1`，2226 重新登录成功。未重启整机，不能把服务恢复验证当作整机冷启动验收。

基线版本：**Ubuntu 24.04.2 LTS / 6.11.0-17-generic / NVIDIA 595.112.07**。新脚本 `ops/pro6000-tunnel/protect-platform.py` 仅修改策略并备份，不安装或更新包：

1. APT 负优先级规则阻止新装/替换内核、匹配头文件及模块、内核元包、固件和 NVIDIA 驱动族；已安装相关包同时 hold。
2. unattended-upgrades 排除上述包，并关闭自动重启和自动清理旧内核。原有其他软件安全更新策略保留。
3. `/etc/update-manager/release-upgrades` 设置 `Prompt=never`，关闭发行版升级入口。

实际 `apt-cache policy` 确认源中的 7.0.0-38 候选为优先级 -1；`apt-get -s upgrade` 未计划任何内核或 NVIDIA 包变化。本轮没有执行实际软件升级。`apt update` 只刷新索引；日后安装普通软件仍应先检查 `apt-get -s install 软件名`，不要使用 `--allow-change-held-packages`、直接安装新内核 deb 或运行发行版升级工具来绕过保护。

策略文件：

- `/etc/apt/preferences.d/99-gaasd-pro6000-platform`
- `/etc/apt/apt.conf.d/99-gaasd-pro6000-platform`
