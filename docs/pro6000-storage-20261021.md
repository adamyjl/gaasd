- `/etc/fstab` 按数据盘 UUID 挂载到 `/data`，选项为 `defaults,nosuid,nodev,nofail,x-systemd.device-timeout=10s`，检查顺序为 `0 2`。已通过 `findmnt --verify` 并从生成的 `data.mount` 单元成功启动，`SourcePath=/etc/fstab`。数据盘不可用时不阻塞正常启动；未执行整机重启验证。
- 数据盘 ext4 特权预留由 5% 调为 1%，增加普通用户可用空间约 76.31 GiB，仍预留约 19.08 GiB；系统盘预留保持原值。预留比例不是个人配额。
- `/data` 的磁盘根目录为 `root:root`、0755；底层空挂载点以 0555 创建，避免磁盘缺失时普通用户向系统盘写入同一路径。
- `/data/yin` 及其子目录为 `lenovo:lenovo`、0700。`/home/lenovo/data` 是指向 `/data/yin` 的软链接。当前没有额外创建 `yin` 系统登录账户或设置容量配额。

- 系统原有 `fstrim.timer` 已启用；保留其设置。没有修改系统盘、EFI 分区、Swap、SSH 隧道或应用环境。
- 腾讯云只读采样已经包含 `/data`；`/status5` 的文件系统表与 `/status1` 的该机器可用空间汇总自动使用新数据，不需要发布网页代码。

## 使用建议

登录后可以直接使用：

```sh
cd ~/data
mkdir -p projects/my-project
df -hT / /data
findmnt /data
```

项目代码放 `projects`，数据集放 `datasets`，模型权重放 `models`，检查点和实验结果放 `outputs`，独立 Python/Conda 环境放 `envs`，下载和框架缓存放 `cache`。新建虚拟环境时显式指定 `/data/yin/envs/<环境名>`，下载或训练时显式指定相应数据盘路径。现有家目录和应用缓存没有自动迁移。

当前个人目录采用文件夹管理，动态共享数据盘空闲容量，不需要为每个项目再划分固定分区。建议保留约 10% 空间作为工作余量；多人使用时，一人一个 Linux 账户和 `/data/<用户名>`，目录归属对应账户并保持 0700，必要时再设置用户配额。同一个 `lenovo` 账户下的不同 SSH 公钥不构成用户间权限隔离。

项目代码、不可重建数据和重要结果应定期备份到另一台机器或独立存储；两块本机 SSD 没有配置 RAID，本次配置备份也不是用户数据备份。
