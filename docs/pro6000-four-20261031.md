## 硬件与软件

四台实测机型均为 ThinkStation P3 Tower Gen 2（30HSA1F2CW），BIOS S0MKT1AA，Intel Core Ultra 9 285K 的 24 个逻辑核全部在线。每台均为 4×32GB TYFC-32GB-6000 DDR5，配置速率 4800 MT/s，双 R800 40Pro 2TB NVMe，Intel 8086:550c 和 Realtek RTL8125 两个有线控制器。每台的 RTX PRO 6000 Blackwell Max-Q Workstation Edition 均报告 97,887 MiB、300W 功耗上限。四台同时执行短时 CUDA 整数运算，每台 65,536 个结果全部回读正确。

四台均为 Ubuntu 24.04.5 LTS、6.17.0-1032-oem、NVIDIA 595.112.07。1,551 个已安装 deb 软件包的名称及版本逐项一致，10 个 Snap 的版本和修订也一致。SSH、ZeroTier、ToDesk、图形显示服务均在运行。检查时 systemd 无失败单元，本次启动日志筛查未见 NVIDIA Xid、内核 Oops 或 NVMe 超时。验收范围为当前启动和短时功能测试，未执行整机重启或长期满载稳定性测试。

**数据盘挂载存在差异，按用户要求保留。** 01–03 的 ext4 数据盘在 `/mnt/nvme0n1p1`。04 的这个路径挂的是 EFI 分区，与 `/boot/efi` 指向同一设备。04 的 2TB ext4 数据分区是 `/dev/nvme1n1p1`，核验时挂在 `/media/lenovo/bc8bb0c3-909e-4e40-b7e8-20bf9a2ddccc`。在 04 上执行数据或训练测试时应使用其实际数据盘路径。01–03 的腾讯云出口为 enp130s0，04 为 enp128s31f6。

## 接入与核验

- 逐台通过 ZeroTier 读取 DMI 序列号后加入 LG 和 adamyjl 的 RSA 公钥。LG 实测四路跳转签名登录成功。adamyjl 的公钥分别获得四台 SSH 服务端接受，完整签名登录须使用 adamyjl 电脑上的私钥。
- 01、02 新系统使用新的主机与隧道密钥。核对旧采样与当前 GPU UUID 后，沿用原主机 ID、端口和历史目录。更换前已备份云端旧授权与主机公钥记录。03、04 新建独立采集身份与目录。
- 安装器参数为 `--profile 主机ID`，云端监控初始化使用 `provision-monitor.py 主机公钥文件 --host 主机ID`。每台的 `gaasd-主机ID-tunnel.service` 已自启，SSH 会话断开后 10 秒重试。ZeroTier 虚拟网卡 MTU 为 1280，校正定时器运行正常。云端监控通过受限 SSH 执行用户级探针，独立 venv 中使用 psutil 7.2.2。任意 `id` 命令均被采集密钥拒绝。
- 版本保护按四台当前平台安装，每台 29 个相关软件包 hold，发行版升级设置为 `Prompt=never`。接入前后逐台比对 deb 软件包名称和版本，均相同。模拟升级未列出受保护的内核、固件或驱动变更。
- 后端 125 项测试、监控浏览器 12 项测试通过。正式站 Chrome 在 1440px 和 390px 实测四台快照、GPU 身份、独立历史、选择器与刷新。匿名访问页面及历史 API 返回 401。验收时四台均为新鲜样本。
