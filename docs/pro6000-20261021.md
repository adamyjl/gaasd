## 采购要求逐项核对

| 项目 | 实际证据 | 结论 |
| --- | --- | --- |
| CPU ≥ Ultra 9 285K | `lscpu` 为 Intel Core Ultra 9 285K，24 核 / 24 线程 | 符合 |
| ≥4×32GB DDR5 UDIMM | DMI 四个插槽均为 Samsung 32GB DDR5，型号 M323R4GA3PB0-CWMOD；机器采用 UDIMM 插槽 | 数量、容量、DDR5 符合；UDIMM 按平台和部件型号核对 |
| RTX PRO 6000 Blackwell Max-Q Workstation Edition 96GB | `nvidia-smi` 完整型号匹配，驱动可用显存 97,887 MiB（约 95.59 GiB），功率上限 300W | 符合型号；可用显存略小于标称容量不代表降配 |
| ≥2×2TB NVMe | 两块 R800 40Pro 2280 PCIe4.0 SSD 2TB，各 2,048,408,248,320 字节，分别 nvme0n1 / nvme1n1 | 符合 |
| ≥3 个 3.5 英寸 SATA 扩展位 | 官方平台支持第三个盘位，但第二/第三盘位属于选配 | 支持能力符合；实际托架、线缆是否齐备待实物确认 |
| 前面板 USB / 音频 | 官方列 4×USB-A 3.2 + 1×USB-C 3.2，Combo 和独立麦克风接口 | 型号规格符合；插口实物与功能未逐个测试 |
| 后面板 ≥4×USB3.2、HDMI2.1 TMDS、2×DP1.4、RJ45 | 官方标准后部是 **2×USB3.2 + 2×USB2.0**，HDMI/DP/RJ45 对应型号支持；本机 PCI 清单未发现额外独立 USB 控制器 | **USB3.2 数量有疑点，不能判定满足；需检查扩展卡及后面板实物** |
| 千兆网口 + 2.5G 网口 | Intel 有线口支持 1000baseT，当前 1000Mb/s 链路；Realtek RTL8125 支持 2500baseT，目前未插线 | 网卡配置符合；未实测 2.5G 吞吐 |
| 1100W 电源 | DMI 没有 type 39 电源记录；同型号有 500/750/1100W 选项 | 待电源铭牌或出厂配置单确认；GPU 300W 上限不是电源功率 |
| 塔式且 ≤27L | 实机 DMI 为 P3 Tower Gen 2，联想标称 27L 塔式 | 按型号规格符合，未实测外形尺寸 |
| ≥3 年上门售后 | 系统无法读取服务合同；同型号存在不同保修选项 | 待序列号保修查询或采购合同确认 |

内存额定 5600 MT/s，当前配置速度 **4400 MT/s**。联想规格明确四条 32GB 配置按 4400 MT/s 运行；采购要求没有限定运行频率，不据此认定容量或配置不合格。

初次核查时，系统盘为 nvme1n1p2，另一块 nvme0n1p1 已有 ext4 但未挂载。2026-10-21 晚按用户要求完成第二块盘只读核查、SMART 检查和持久挂载，作为 `/data` 提供约 1.81 TiB 可用空间，已准备 `/data/yin` 个人目录。保留原分区和文件系统，详细配置、健康记录及备份见 [数据盘启用记录](pro6000-storage-20261021.md)。

总体结论：核心计算硬件、内存容量、NVMe 数量与双网卡配置达到要求；**整机暂不能标记为全部验收通过**。后置 USB3.2 数量需要优先落实，电源、扩展托架、上门服务期限尚缺交付证据。

型号规格参考：[联想官方 PSREF](https://psref.lenovo.com/syspool/Sys/PDF/ThinkStation/ThinkStation_P3_Tower_Gen_2/ThinkStation_P3_Tower_Gen_2_Spec.pdf)。该资料描述平台及可选配置，不能代替本机出厂装箱清单。未将设备序列号、密码或完整 DMI 导出提交 Git。
