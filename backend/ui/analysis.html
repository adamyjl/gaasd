02 / CPU

单线程 SHA-256 吞吐

MiB/s · 数值越大，本项运算越快

相同 1 MiB 数据块，3 次 × 0.6 秒，取中位数。结果受 SHA 指令、OpenSSL 和运行负载影响，不是 CPU 综合跑分；未采到的数据不填零、不参与排序。

逻辑线程 / vCPU 容量

线程数 · 仅比较分配容量，不代表性能倍数

腾讯云仅统计虚拟机实际获配 vCPU，不把宿主机 EPYC 型号中的 64 核算作可用核心。混合架构 P/E 核、超线程与物理核也不能等价换算。

03 / GPU

GPU：算力和模型容量分别比较

TFLOPS · CUDA 普通单精度运算，非 Tensor / FP4

多卡为单卡规格乘数量的算术合计，不是实测多卡加速。A100 的 HBM、NVLink 和混合精度优势不由此图反映，不能据此断言训练慢于消费卡。

整机标称显存合计

GB · 容量越大，可承载的模型和批次空间越多

8 张卡的显存不会自动合并成一个地址空间；单卡可容纳模型仍受单卡显存限制。这里为厂商标称容量，监控中的可用容量可能因保留区而略低。

METHODOLOGY

如何读这些图

CPU 实测比较特定单线程运算；线程数量比较资源容量。GPU 理论峰值比较同一种 FP32 精度；不混用稀疏 FP4 TOPS、Tensor 或 FP64。

未运行长时间 CPU 或 GPU 压测，不打断现有任务。离线机器沿用最后硬件清单，并单独标注；未测的 CPU 性能保留为空。

AI 仅接收脱敏后的任务名、选定参数、GPU 指标和进度摘要，没有执行命令的能力。失败时保留上一轮分析并提示，不把旧结果冒充实时。
