延迟与使用量说明

A100 的 ping 从腾讯云经 OpenVPN 发出。其余内网主机通过反向 SSH 转发，腾讯云没有直达这些私网地址的 ICMP 路由，因此显示目标主机到腾讯云公网的 ping；并单独显示云端经隧道读取采样的耗时（包含 SSH 握手与采集）。未响应不显示成 0 ms，也不据此单独判定主机离线。

CPU 为整机占用率；内存为总量减可用；GPU 为驱动采样值；网络为非回环接口流量，虚拟接口可能重复计数。进程只显示名称和资源指标，不读取命令参数或环境变量。各卡型号不同，不将利用率换算成统一计算量或算力。

日／周 GPU 历史在 A100 与 4090 / 5090 详情页查看；新接入机器从首次成功采样开始积累，不补造历史。采样保存在腾讯云，关闭浏览器或维护电脑不影响采集。
