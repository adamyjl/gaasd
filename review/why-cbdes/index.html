WHY CBDES / 01

Why is a new approach to autonomous driving development needed?

From algorithm design and software integration to deployment and on-board verification, R&D must connect multiple stages. How can mature capabilities be reused, and how can each round of verification drive the next iteration of development?

01SAFETY

Software Safety Risks

Tightly coupled algorithms, application functions, and underlying platforms make the impact of changes difficult to isolate and expand the scope of safety verification.

SolutionLayered decoupling and prefabricated functional software
02DEVELOPMENT COST

High Development Costs

Similar functions are developed repeatedly across application domains. Existing modules are difficult to share, increasing the cost of application refactoring.

SolutionCross-domain reuse for application refactoring
03DEVELOPMENT EFFICIENCY

Low Development Efficiency

When algorithm design is tied to code implementation, each algorithm change requires repeated coding and integration, slowing development iterations.

SolutionDecouple algorithm design from code development
